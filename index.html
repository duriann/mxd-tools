    远程消息提醒

    请在 HTTPS 网页或通过 Windows 启动器配置远程推送。

    提醒事件
    PushPlus 推送加
    注册或登录 PushPlus
    1. 登录后完成付费实名认证，在「一对一消息」找到「用户 Token」，点击「一键复制」。
    2. 微信接收时关注「pushplus 推送加」服务号。QQ 接收时在「个人中心 → 渠道配置 → QQ 机器人」扫码绑定，发群时先在那里新增群配置。手机 App 登录同一账号并开启系统通知。
    3. 把 Token 粘贴到下方，勾选已绑定的渠道，再点该渠道的「发送测试」。普通短信的试发会扣费。

    微信 ClawBot 扫码绑定后，给机器人发一条消息以激活。新消息 ClawBot 仅支持中国移动用户，需在 PushPlus 绑定 Channel API Key。普通短信需绑定手机号并充值积分。查看各渠道绑定步骤

    多个渠道各占用请求额度。
    Qmsg 酱
    注册或登录 Qmsg 酱
    1. 点击「开始使用」，用 QQ 登录，在控制台复制 API Key。
    2. 扫描控制台二维码添加机器人，按提示私聊发送 API Key 完成绑定。发群时先在控制台添加并绑定目标群。
    3. 把 API Key 粘贴到下方，勾选「启用 Qmsg 酱」，再点「发送测试」。发给自己时群号留空。
    Server 酱 Turbo
    注册或登录 Server 酱 Turbo
    1. 用微信扫码登录，到控制台「SendKey」复制以 SCT 开头的密钥。
    2. 在控制台「消息通道」确认已选微信服务号，按页面提示关注服务号。
    3. 把 SendKey 粘贴到下方，勾选「启用 Server 酱 Turbo」，再点「发送测试」，到微信服务号会话查看。
    收到测试消息后，选择提醒事件，再打开「启用远程消息提醒」总开关。
